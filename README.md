# GearHUD (Fabric 1.21.4)

Prawy dolny rog: karty graczy w poblizu - glowa, nick, dystans, HP, set (helm/klata/spodnie/buty
z paskiem wytrzymalosci) i miecz (podswietlony akcentem).
Kolor akcentu zalezy od wymiaru: Overworld zielony, Nether pomaranczowy, End fioletowy.

Klawisze (zmienisz w Opcje -> Sterowanie -> GearHUD):
- H - wlacz/wylacz
- J - tryb: zawsze / tylko w Netherze

Build: wrzuc na GitHub -> zakladka Actions -> artefakt `gearhud` (jar). Lokalnie: `gradle build`.
